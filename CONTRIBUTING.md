## Contributing to graphql-schema-utils

We welcome contributions from the community! Before submitting a pull request, please ensure that:

- You have read and understood the [project documentation](https://github.com/SeanDing/graphql-schema-utils).
- You are addressing a specific issue or adding a new feature.
- Your code is well-documented and follows the project's coding standards.
- You have written relevant unit tests for your changes.
- You have ensured that all tests pass locally before submitting your PR.

### Steps to Contribute
1. Fork the repository and create a new branch for your changes.
2. Make your changes and ensure they are well-documented.
3. Write tests for your new features or bug fixes.
4. Run all tests and ensure they pass.
5. Submit a pull request against the `main` branch.

### Pull Request Template

When creating a pull request, please use the following template:

```markdown
### Summary
- What is the purpose of this change?
- What problem does it solve?

### Changes
- List the key changes made in this PR.
- Are there any breaking changes? If so, mention them here.

### Testing
- How were the changes tested?
- Are there any new tests added? If so, mention them here.

### Documentation
- Is there any new documentation or updates to existing documentation?
- If so, mention what was added or changed.

### Screenshots (if applicable)
- Add any relevant screenshots here.
```
